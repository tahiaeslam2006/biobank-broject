# Biobank and Biospecimen Management System

## Project Overview
The Biobank and Biospecimen Management System is a database project developed to organize and manage information related to donors, biospecimen samples, sample types, storage locations, researchers, test requests, instruments, and test results.

The system helps keep the data organized and connects the different parts of the biobank through relationships between the database tables.

## DBMS Used
MySQL

## Execution Instructions
1. Open MySQL Workbench and connect to the MySQL server.
2. Run `create_tables.sql` to create the database and its tables.
3. Run `load_data.sql` to insert the sample data.
4. Run `views.sql` to create the required views.
5. Run `triggers_procedures.sql` to create the trigger and database logic.
6. Run `queries.sql` to test the database and display the required results.
